BLOGNOVA WORDPRESS THEME
==========================

Files:
- style.css       -> design and layout
- functions.php   -> theme setup and CSS loading
- header.php      -> HTML <head> and website header
- index.php       -> main blog homepage and WordPress Loop
- footer.php      -> footer and wp_footer()
- screenshot.png  -> theme preview

INSTALL:
1. Copy the blognova folder into:
   wp-content/themes/

2. Go to WordPress Dashboard:
   Appearance > Themes

3. Activate BlogNova.

4. Create some Posts.
5. Add Featured Images to your posts.
6. Create Primary and Footer menus:
   Appearance > Menus
7. Assign the menus to their theme locations.

IMPORTANT:
The image URLs in index.php and style.css are demo images from Unsplash.
For a real theme, replace them with local/theme images or WordPress featured images.
